GAME ARENA - COMPLETE PROJECT

This is the consolidated Game Arena Gaming Tournament Portal.
All previously developed steps are included in this single project.

Included modules:
1. Home / Landing Page
2. Authentication (Login / Register)
3. User Dashboard
4. Games & Tournaments
5. Tournament Registration
6. Team Creation & Team Management
7. Matches
8. Leaderboard
9. User Profile & Settings
10. Notifications & Announcements
11. Admin Dashboard
12. Tournament Creation / Management
13. Slot & Participant Management
14. Tournament Bracket & Round 1 Generation
15. Live Match & Score Management
16. Automatic Winner / Draw Result
17. Leaderboard updates after completed matches
18. Responsive gaming UI and localStorage data persistence

HOW TO RUN:
- Extract the ZIP.
- Open index.html in a browser.
- For administration, open admin.html.
- No server/database is required for the current college-project version.
- Data is stored in browser localStorage.

IMPORTANT:
Open the files from the same extracted folder so the assets folder remains available.
